# RecuperacionDEW
 ## Funcionamiento
- Para la prueba del proyecto, hay que ejecutar la pagina de login.html, luego logearse con un usuario nombre--> emilys, password--> emilyspass. Luego entrara a la pagina principal, donde puede selecionar productos para añadirlo al carrito, si se seleccionar un producto se le agregara a carrito, hay puede aumentar la cantidad, disminuilar, eliminar ese solo producto, tambien puede vaciar todo el carrito y realizar la compra. Tambien puedes dirigirte al grafico (Chart) y si eres admin puedes entrar ademas del grafico al crud de producto. En el chart hay un grafico donde esta todo los producto y muestra cuando cuesta el valor. En el crud de producto esta la lista de todo lo producto, se puede crear, eliminar y editar los productos
